# Dashboard v3 — Delivery & Service Quality

![Delivery & Service Quality Dashboard](../images/olist_delivery_service_dashboard.png)

## Бизнес-задача

Оценить качество доставки Olist, найти периоды и регионы повышенного риска и проверить, как отклонение от обещанного срока связано с клиентской оценкой.

Дашборд предназначен для руководителя e-commerce, операционной и клиентской команд. Он переводит логистические события в понятные управленческие метрики: долю своевременной доставки, число опоздавших заказов, фактический срок доставки и среднее превышение обещанной даты.

Базовый период анализа: **01.01.2017–31.08.2018**. В расчёты сроков входят только заказы с заполненной датой фактической доставки.

## Ключевые KPI

| Метрика | Определение | Значение |
|---|---|---:|
| Доставка вовремя | доставленные вовремя или раньше / все доставленные заказы | **93,2%** |
| Поздние заказы | `COUNTD(order_id)` при `Delay Days > 0` | **6 532** |
| Средний срок доставки | среднее число календарных дней от покупки до доставки | **12,5 дня** |
| Среднее опоздание | среднее превышение обещанного срока среди поздних заказов | **10,6 дня** |

Доля поздних заказов составляет **6,8%** от 96 204 заказов с известной датой доставки.

## Расчётная логика

```tableau
// Delay Days
IF NOT ISNULL([order_delivered_customer_date]) THEN
    DATEDIFF(
        'day',
        [order_estimated_delivery_date],
        [order_delivered_customer_date]
    )
END

// Delivery Group
IF ISNULL([order_delivered_customer_date]) THEN
    'Not delivered'
ELSEIF [Delay Days] > 0 THEN
    'Late'
ELSE
    'On time or early'
END

// Late Rate
COUNTD(IF [Delivery Group] = 'Late' THEN [order_id] END)
/
COUNTD(
    IF [Delivery Group] IN ('Late', 'On time or early')
    THEN [order_id]
    END
)
```

`Delay Days = 0` означает доставку в обещанный календарный день, отрицательное значение — досрочную доставку, положительное — опоздание.

## Визуализации

### Доля опозданий по месяцам

Линия показывает, что логистический риск менялся неравномерно. Максимум базового периода приходится на **март 2018 года — 19,0%**, поэтому одного общего среднего недостаточно для операционного контроля.

### Распределение сроков доставки

Гистограмма показывает форму распределения фактического срока доставки в диапазоне до 60 дней. Большая часть заказов доставляется примерно за 4–14 дней, после чего формируется длинный правый хвост редких длительных доставок.

### Топ-10 штатов по доле опозданий

Наибольшая наблюдаемая доля опозданий среди показанных штатов — в `AL` (**21,5%**), затем `MA` (**17,5%**) и `SE` (**15,4%**). Рейтинг следует использовать вместе с абсолютным числом заказов: высокий процент в небольшом штате не равен максимальному влиянию на общий SLA.

### Средняя оценка по срокам доставки

Оценка последовательно снижается с ухудшением исполнения обещания:

- раньше на 7+ дней — **4,3**;
- в обещанный день — **4,0**;
- опоздание на 1–3 дня — **3,3**;
- опоздание на 4–7 дней — **2,1**;
- опоздание на 8+ дней — **1,7**.

В агрегированном сравнении своевременные заказы получают в среднем **4,29**, поздние — **2,27**. Разница составляет **2,02 балла**.

### Распределение оценок по сроку доставки

Состав оценок визуально сравнивается для своевременных и поздних заказов. Проверка исходных данных показывает, что доля негативных оценок 1–2 балла составляет около **9,3%** для своевременной доставки и **62,4%** для поздней — примерно в **6,7 раза выше**.

## Выводы и действия

1. Общий SLA выглядит высоким, но месячная доля опозданий нестабильна и в пиковом месяце почти втрое выше среднего уровня.
2. Опоздание связано с резким ухудшением клиентской оценки; особенно критичны задержки свыше четырёх дней.
3. Для операционного мониторинга нужен алерт по месячной или недельной доле опозданий, а не только среднее значение за весь период.
4. Для штатов с повышенным риском следует отдельно проверить перевозчиков, маршруты, категории крупногабаритных товаров и точность обещанной даты.
5. При ожидаемой задержке полезна проактивная коммуникация с новым ETA; эффект сообщения или компенсации следует проверять A/B-тестом.
6. В управленческий отчёт стоит одновременно включать Late Rate и объём заказов, чтобы приоритизировать проблемы по потенциальному числу затронутых клиентов.

## QA и ограничения

- заказы считаются через `COUNTD(order_id)`, чтобы товарные позиции не размножали сущности;
- знаменатель Late Rate содержит только заказы с известной фактической датой доставки;
- период ограничен 31.08.2018, чтобы не сравнивать полные месяцы с неполным хвостом данных;
- глобальный Top-10-фильтр штатов удалён: он ранее незаметно уменьшал все KPI; рейтинг штатов теперь не влияет на общие показатели;
- расчёты независимо сверены по CSV внутри переносимой книги `.twbx`;
- связь задержки и оценки является описательной и не доказывает причинность;
- в данных нет перевозчика, стоимости компенсаций и причин задержки, поэтому дашборд показывает место проблемы, но не её коренную причину.

## Решения по дизайну

- summary-first компоновка: четыре KPI → динамика и распределение → география и клиентский эффект;
- оранжевая линия выделяет риск, синяя палитра используется для сравнительных распределений;
- единый процентный формат для Late Rate и своевременной доставки;
- подписи на рейтингах и оценках уменьшают необходимость считывать значения по оси;
- финальное изображение экспортировано непосредственно из Tableau в размере 2732×1800.
