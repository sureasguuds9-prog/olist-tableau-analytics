# Dashboard v1 — Executive Overview

## Бизнес-задача

Создать единый экран для мониторинга масштаба e-commerce, динамики продаж, географической и товарной структуры, а также качества выполнения заказов.

## Логика чтения

1. KPI дают общий масштаб бизнеса.
2. Линейные графики показывают движение GMV и заказов во времени.
3. Категории и карта раскрывают основные драйверы объёма.
4. Доставка, отзывы и статусы показывают качество исполнения.
5. Глобальные фильтры позволяют повторить анализ для выбранного сегмента.

## Принятые определения

| Метрика | Формула | Комментарий |
|---|---|---|
| GMV | `SUM(price + freight_value)` | операционный показатель, не прибыль |
| Orders | `COUNTD(order_id)` | исключает размножение из-за товарных позиций |
| Customers | `COUNTD(customer_unique_id)` | уникальный покупатель Olist |
| AOV | `GMV / COUNTD(order_id)` | средний GMV на заказ |
| Review Score | `AVG(review_score)` | только по доступным отзывам |

## Решения по дизайну

- summary-first компоновка: KPI → тренды → драйверы → качество;
- единый синий цвет для объёма и трендов;
- зелёный/красный для своевременной и поздней доставки;
- горизонтальные столбцы для длинных названий категорий;
- filled map для сравнения штатов;
- небольшое число глобальных фильтров, влияющих на весь дашборд.
